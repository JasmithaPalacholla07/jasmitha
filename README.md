🏏 AI Cricket Winner Prediction System

This project uses Machine Learning to predict the winner of a cricket match based on match-related input data.

📌 About the Project

The AI Cricket Winner Prediction System is a Machine Learning project developed as part of my AI and Python learning journey.

The model is trained using cricket match data and predicts the likely winner based on the input provided by the user.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- Jupyter Notebook

📁 Project File

- "AI Cricket Prediction System.ipynb" — Main Jupyter Notebook containing data preprocessing, model training, and winner prediction.

🚀 How to Run

1. Open the ".ipynb" file in Jupyter Notebook or VS Code.
2. Run all the cells.
3. Provide the required match inputs.
4. The trained Machine Learning model predicts the winner.

🎯 Project Objective

The main objective of this project is to understand how Machine Learning classification algorithms can be applied to cricket match prediction.
